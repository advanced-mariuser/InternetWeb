# Техническое Задание: Базовый RDTP

### Разработайте программу на C/C++, которая обеспечивает:
- **Архитектура "Клиент-Сервер":**
  - **Отправитель (Sender):** Читает файл, разбивает на пакеты, отправляет, получает ACK
  - **Получатель (Receiver):** Принимает пакеты, собирает файл, отправляет ACK
- **Реализация алгоритма:**
  - На выбор: Go-Back-N (GBN) или Selective Repeat (SR)
  - Использование скользящего окна для управления потоком
  - Корректная обработка таймаутов и повторных передач
- **Симуляцию ненадежного канала:**
  - Внесение случайных потерь пакетов и ACK
  - Внесение случайных задержек
  - (Опционально) Внесение ошибок в контрольную сумму

- **Пример использования:**
<br>./rdt_sender <receiver_host> <receiver_port> <file.txt>
<br>./rdt_receiver <receiver_port> <received_file.txt>
## Критерии оценки и требования к реализации

**Язык программирования:** C/C++ <br>
**Системные вызовы:** socket(), bind(), sendto(), recvfrom(), close(), select() / poll()<br>
**Формат вывода:**
- Обычный режим: Прогресс передачи, итоговая статистика (скорость, % потерь)
- Режим отладки (-d): Подробный лог каждого события: отправка пакета №X, получение ACK №Y, тайм-аут на пакете №Z

**Корректность работы:** 
- Безошибочная передача файла в условиях потерь
- Эффективное использование полосы пропускания (не простаивать!)

**Освобождение ресурсов:** Все сокеты должны быть корректно закрыты

## Что необходимо сдать?
- **Исходный код:** Файлы rdt_sender.c(pp), rdt_receiver.c(pp) и вспомогательные модули
- **Документ по проектированию:** Описание формата пакетов, конечного автомата (state machine) и выбранных алгоритмов (2-3 страницы)
- **Примеры выходных данных:** Скриншоты, демонстрирующие:
    - Скриншот полученного письма
    - Логи, демонстрирующие обработку потерь и тайм-аутов
    - (Для продвинутого уровня) Графики и сравнительная таблица GBN vs SR.
