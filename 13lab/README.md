# Техническое Задание: UDP Pinger Клиент

### Разработайте программу на C/C++, которая обеспечивает:
  - Отправку 10 ping-запросов на сервер
  - Тайм-аут 1 секунда на ожидание ответа
  - Расчет RTT (Round-Trip Time) для каждого полученного ответа
  - Визуализация результатов: вывод ответов сервера или "Request timed out"

### Пример каркаса кода
```c++
// Псевдокод структуры клиента
for (10 пакетов) {
  запомнить время отправки
  отправить UDP пакет
  установить тайм-аут 1 секунда
  
  if (ответ получен вовремя) {
    вычислить RTT = текущее_время - время_отправки
    вывести ответ + RTT
  } else {
    вывести "Request timed out"
  }
}
```

### Формат сообщений
Ping sequence_number timestamp
- Например:<br>
Ping 1 1630578123<br>
Ping 2 1630578124<br>
...<br>
Ping 10 1630578132<br>

**Где:**
- sequence_number - номер последовательности (1-10)
- timestamp - время отправки в миллисекундах

## Критерии оценки и требования к реализации

**Язык программирования:** C/C++ <br>
**Системные вызовы:** socket(), sendto(), recvfrom(), setsockopt(), gettimeofday(), close()<br>
**Формат вывода:**
```
Ответ от сервера: PING 1 1630578123, RTT = 0.045 сек
Ответ от сервера: PING 2 1630578124, RTT = 0.023 сек
Request timed out
...
```
**Корректность работы:** 
- Точный расчет RTT
- Корректная обработка тайм-аутов
- Правильная работа с сокетами

**Освобождение ресурсов:** Все сокеты должны быть корректно закрыты
