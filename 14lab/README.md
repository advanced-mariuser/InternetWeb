# Техническое Задание: Базовый прокси-сервер

### Разработайте программу на C/C++, которая обеспечивает:
- Прием HTTP GET-запросов от клиентов
- Перенаправление запросов на целевые веб-серверы
- Кэширование полученных объектов на диск
- Обслуживание из кэша при повторных запросах
- Обработку ошибок (404 Not Found, сетевые ошибки)

### Псевдокод структуры
```c++
while(1) {
    // Принять соединение от клиента
    // Проанализировать HTTP-запрос
    // Извлечь имя хоста и путь к файлу
    // Проверить наличие в кэше
    if (файл_в_кэше) {
        отправить_из_кэша();
    } else {
        подключиться_к_целевому_серверу();
        получить_данные();
        сохранить_в_кэш();
        отправить_клиенту();
    }
}
```

### Формат запросов и работа прокси
**Пример запроса клиента:**
GET http://www.example.com/index.html HTTP/1.0

**Прокси извлекает:**
- Хост: www.example.com
- Путь: /index.html
- Порт: 80 (по умолчанию для HTTP)

**Прокси создает запрос к целевому серверу:**
GET /index.html HTTP/1.0
Host: www.example.com

## Конфигурация браузера для тестирования
**Ручное указание прокси:**
- **Firefox**: Настройки → Прокси сети → Ручная настройка прокси
- **Chrome**: Параметры → Дополнительные → Система → Настройки прокси-сервера
- **Указать**: IP и порт вашего прокси-сервера

**Тестирование через URL:**
- http://localhost:8888/www.google.com
- http://your_proxy_ip:8888/www.example.com

## Критерии оценки и требования к реализации

**Язык программирования:** C/C++ <br>
**Системные вызовы:** socket(), bind(), listen(), accept(), connect(), send(), recv()<br>

**Требования к реализации:**
- Корректная обработка HTTP GET запросов
- Рабочее кэширование различных типов контента (HTML, изображения)
- Обработка ошибок (404, тайм-ауты соединения)
- Освобождение всех ресурсов (сокеты, файловые дескрипторы)

**Формат вывода:**
- Логирование всех операций (принят запрос, кэш-попадание, кэш-промах)
- Статистика работы прокси
