# Техническое Задание

### Часть 1: Подготовка сервера
- Создать TCP-сокет
- Привязать к порту (>1023, рекомендуется 8080 или 8888)
- Начать прослушивание (listen).

### Часть 2: Подготовка сервера
- Принимать соединения (accept)
- Читать HTTP-запрос
- Извлекать имя запрашиваемого файла
- Отправлять HTTP-ответ

### Техническое Задание: HTTP-ответы
**Успешный ответ (200 OK):**<br>
HTTP/1.1 200 OK<br>
Content-Type: text/html <br>
<содержимое файла>

**Ошибка (404 Not Found):**
HTTP/1.1 404 Not Found<br>
Content-Type: text/plain<br>
File Not Found<br>

### Пример каркаса кода
```c++
int main() {
    int server_socket = socket(AF_INET, SOCK_STREAM, 0);
    // ... привязка, listen
    while(1) {
        int client_socket = accept(server_socket, NULL, NULL);
        char buffer[1024];
        read(client_socket, buffer, sizeof(buffer));
        // Парсим GET /index.html HTTP/1.1
        // Открываем файл
        // Отправляем заголовок + содержимое
        // Или 404 если файла нет
        close(client_socket);
    }
}
```

## Критерии оценки и требования к реализации

**Язык программирования:** C/C++ <br>
**Системные вызовы:** socket(), bind(), listen(), accept(), read(), write(), close()<br>
**Порт:** > 1023 (рекомендуется > 5000)<br>
**Обязательный функционал:**
- Обработка GET-запросов
- Корректные HTTP-ответы 200 и 404
- Чтение и отправка файлов
- Информативный вывод в консоль

**Освобождение ресурсов:** Все сокеты должны быть корректно закрыты
