# Техническое Задание: Базовый DNS резолвер

### Разработайте программу на C/C++, которая обеспечивает:
- **Ввод данных:**
  - Принимает аргументы командной строки: доменное имя и тип записи (A/AAAA или другие)
  - Опциональный флаг -d для включения режима отладки
- **Итеративное разрешение:**
  - Начинает с корневых серверов DNS
  - Последовательные запросы к серверам имен каждого уровня
  - Завершение при получении конечного IP-адреса
- **Обработку ответов:**
  - Извлечение и анализ DNS записей
  - Обработка ошибок (хост не найден, сетевые ошибки)
  - Корректное завершение работы

- **Пример использования:**
<br>./dns_resolver example.com A
<br>./dns_resolver example.com AAAA -d
<br>./dns_resolver example.com DNSSEC -d
## Критерии оценки и требования к реализации

**Язык программирования:** C/C++ <br>
**Системные вызовы:** socket(), connect(), read(), write(), close()<br>
**Порт:** 25<br>
**Формат вывода:**
- Обычный режим: только конечный результат
- Режим отладки: подробная информация о каждом шаге, включая внутренние  монологи программы

**Корректность работы:** 
- Точное соблюдение DNS протокола
- Правильная обработка всех типов ошибок, включая "сервер сказал 'нет'"

**Освобождение ресурсов:** Все сокеты должны быть корректно закрыты

## Что необходимо сдать?
- **Исходный код:** Файлы dns_resolver.c или dns_resolver.cpp.
- **Документ по проектированию:** Описание алгоритма обработки TC флага (1-2 страницы)
- **Примеры выходных данных:** Скриншоты, демонстрирующие:
    - Обычное разрешение через UDP
    - Автоматический переход на TCP при TC флаге
    - Отладочную информацию о смене протоколов
